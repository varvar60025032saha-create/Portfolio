# stasheuskaya. — Graphic & Interactive Design Portfolio

Портфолио Варвары Сташевской — графический и интерактивный дизайн, айдентика, брендинг, плакаты, мультимедиа. Студентка WSB Merito Gdańsk.

## Стек технологий
- HTML5 / CSS3 / Vanilla JavaScript (ES6+)
- Typography: Space Grotesk, Inter, JetBrains Mono
- SVG Graphics & Custom Vector Branding
- Responsive Dark Editorial Aesthetic
- Formsubmit AJAX integration

## Структура сайта
- `index.html` — главная страница портфолио
- `css/style.css` — стили, анимации, адаптив и дизайн-система
- `js/main.js` — интерактивные модальные окна, фильтры кейсов, интерактивный просмотр
- `assets/` — оптимизированная графика, кейсы, постеры, фавиконы и иконки
